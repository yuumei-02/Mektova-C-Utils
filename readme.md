# About
Mektova-C-Utils, mcu for short, is my personal C standard library build ontop of libc and posix. <br>
This library adds new data-types, tons of functions for said data-types and APIs for common operations. <br>
Almost all of my C projects use this library. <br>

# Dependencies
Mektova-C-Utils itself doesn't have any dependencies other than *libc* of course. <br>
However, in order to run the test, [Vlodinnye-test](https://github.com/yuumei-02/Vlodinnye-test) must be installed system wide.
which requires Mektova-C-Utils to also be installed system wide. <br>
So, in order to run the test, you must first install both this library and Vlodinnye-test system-wide. <br>
Running test is of course *optional*. <br>
