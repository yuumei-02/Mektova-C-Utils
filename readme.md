# About
Mektova-C-Utils, mcu for short, is my personal C standard library build ontop of libc
and posix.
This library adds new data-types, tons of functions for said data-types and APIs for common operations.
Almost all of my C projects use this library.

# Note
This library is meant for my personal use and does not accept feature request.
You're free to point out bugs and suggest improvements if you wish.
